# Chatbot PDF Generation

## Overview

This module primarily provides the HTML layout, CSS styling, and template structure used in creating PDFs as part of story creation workflows.

## Key PDF Modules

- `story_first_page.py`: Defines the layout and structure for the first page of story PDFs.
- `story_secondpage.py`: Defines the second page layout.
- `story_thirdpage.py`: Defines the third page layout.
- `story_images_page.py`: Manages story image pages within PDFs.
- `story_pdf.css`: Contains CSS controlling PDF styles and formatting.

## Purpose

- Provides reusable page layouts and styles for story PDF generation.
- Supports producing consistent, styled documents from narrative data for export or archival.

This module is used within story creation flows to render multi-page, styled PDFs reflecting chatbot-generated stories and content.
