# Shikshalokam Backend

## What This System Does

This backend powers an AI-driven knowledge and conversation platform.

It enables:

### 1. Conversational AI Workflows
- Free-flow chat
- Guided discussions
- One-shot responses
- Session persistence
- Multi-language support
- Voice (STT/TTS)

### 2. Story Generation
- Converts chat sessions into structured stories
- Supports translation
- Generates formatted outputs (PDF)

### 3. Project Creation
- Converts discussions into structured projects
- Generates timelines
- Creates downloadable reports

### 4. Knowledge Ingestion System
- Upload documents
- Extract metadata using AI
- Auto-tag content
- Store embeddings in vector DB
- Enable semantic search

### 5. Media Intelligence
- Advanced search (FTS + Trigram)
- Metadata filtering
- Tag ranking

### 6. Observability & Evaluation
- LLM test cases
- Evaluation pipelines
- Quality tracking
